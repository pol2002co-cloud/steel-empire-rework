# 강철제국 리워크

Windows 11에서 사용할 수 있도록 개선한 강철제국 리워크 배포 저장소입니다. 최신 누적 버전은 **v0.8.3**입니다.

## 다운로드

[최신 릴리스와 다운로드 파일](https://github.com/pol2002co-cloud/steel-empire-rework/releases/latest)

| 파일 | 용도 |
|---|---|
| `SteelEmpire-Rework-v0.8.3-FullGame.zip` | 게임 데이터·영상·음악과 최신 리워크가 포함된 전체 실행본 |
| `SteelEmpire-Rework-v0.8.3-Update.zip` | 기존 원본 또는 지원되는 리워크 설치를 최신 버전으로 업데이트 |
| `SteelEmpire-Rework-v0.8.3-Tools.zip` | 기본·16:9·QHD 런처, 인물 에디터, 사용법 |
| `SteelEmpire-Rework-v0.8.3-Source.zip` | 패치 제작 코드, 런처·에디터 소스, 검증 코드, 제작용 데이터와 문서 |
| `cnc-ddraw-v7.1.0.0-source.zip` | 함께 제공하는 cnc-ddraw의 해당 버전 소스 |
| `SHA256SUMS.txt` | 다운로드 무결성 확인용 해시 |

전체 게임은 ZIP을 완전히 풀고 `SteelReworkQHD.exe` 또는 `SteelRework.exe`를 실행하세요. QHD 런처는 2560×1440을 포함한 16:9 해상도를 선택할 수 있습니다. 원래 4:3 화면을 가로로 확대하므로 게임 시야 자체가 넓어지지는 않습니다.

## 기존 설치 업데이트

Update ZIP을 별도 폴더에 풀고 게임·런처·인물 에디터를 종료한 뒤 PowerShell에서 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Update.ps1 -GamePath "D:\Games\DGGL\Games\EoSteel_Win"
```

설치 대상 실행 파일과 배포 파일의 해시를 확인하고 `ReworkBackups`에 프로그램 파일을 백업합니다. 기존 `ddraw.ini` 설정과 저장 파일은 유지합니다. 복원은 생성된 백업 폴더의 `Restore-Update.ps1`을 실행합니다. 새 버전에서 저장한 파일이 이전 버전과 항상 호환되는 것은 아니므로, 이전 버전으로 돌아갈 예정이면 저장 파일도 별도로 보관하세요.

## v0.8.3 한글 표시 수정

다른 PC에서 대화·선택창 한글이 깨지는 문제를 수정했습니다. 게임 UI 리소스를 Windows 기본 인코딩 대신 CP949로 변환합니다. Windows 언어·UTF-8 옵션 변경 없이 적용되며, 이미 v0.8.2를 받은 분은 Update ZIP을 설치하면 됩니다. [원인·설치·검증 상세](docs/한글표시-수정-v083.txt)

## 포함된 주요 변경

- 일반 병종 13종의 훈련, 일반 전차·항공기 구매 확장. 보스 전용 장비는 제외.
- 훈련대장 레벨에 비례한 신규 병사 레벨 보너스와 신규 훈련 레벨 30 상한.
- 장갑보병 → 중장갑보병 재훈련 및 재훈련소 UI 오류 수정.
- 포커 승리, 술집 용병을 포커 없이 고용하는 처리.
- 이름 있는 영입 동료의 전투 사망 후 다음 날 복귀. 일반 용병은 기존 처리.
- 모든 도시 항공 부대 진입, 공항 없는 도시에서도 A 키로 공항 화면을 열어 출격.
- 적 군단장 사망 후 3턴 기한에 남은 적 자동 전멸, 브라보니케 치트의 즉시 승리 정산.
- 미니맵 도시명은 마우스 호버 시 표시.
- 개인 전투 경험치 200 상한 제거, 이미 99레벨인 생존자의 경험치를 99 미만 생존자에게 재분배.
- 새로 생성되는 적 용병단의 특성별 최대 편성 확장.
- 상점 메달 7종 구매, 인물 에디터의 능력치·상태·지휘/특수능력 편집.
- F8 이벤트 진행창: 주요 사건 9개, 현재 단계, 모든 발동 조건과 분기 공개.
- 미진행 사건의 조건 무시 예약. 이미 시작·거절·완료한 사건은 재실행 차단.
- 보상받은 의뢰가 남고 다른 의뢰가 삭제되는 원본 의뢰 삭제 오류 수정.

[누적 패치 노트](docs/CHANGELOG.md)와 [배포 파일 구성](docs/DISTRIBUTION.md)을 참고하세요.

## 검증 범위와 저장 호환

코드 비교와 기계어 에뮬레이션으로 전투, 재훈련 UI, 경험치 분배, 이벤트 판정, 의뢰 삭제 경로를 검사했습니다. 모든 스토리 분기의 실제 게임 완주를 검증한 배포는 아닙니다. 원래 배타적인 이벤트를 함께 진행하면 후속 이야기의 정상 완주를 보장할 수 없습니다.

6칸 재훈련 데이터가 기록된 저장은 v0.5 이하에서 읽으면 안 됩니다. 이벤트 강제 예약은 기존 저장 영역의 미사용 칸에 보관하며, 저장 파일 길이는 바꾸지 않습니다. v0.8.2부터 포함된 의뢰 수정은 다른 사용자의 지급 완료 의뢰를 추정해서 삭제하지 않습니다. 특정 개인 저장에 수행했던 보석지팡이 복구는 공개 패키지에 포함하지 않았습니다.

## 권리 및 구성요소

원본 게임의 저작권은 원권리자에게 있습니다. 이 저장소의 공개 준비 과정에서 배포자는 게임 전체 재배포 허가를 보유한다고 확인했습니다. 원본 게임과 제3자 구성요소에 새로운 오픈소스 라이선스를 부여하지 않습니다. 별도의 재배포·상업적 이용 허락까지 이 저장소가 제공하는 것은 아닙니다.

cnc-ddraw v7.1.0.0의 라이선스는 `third-party/cnc-ddraw-LICENSE.txt`, 해당 버전 소스는 릴리스의 별도 ZIP으로 제공합니다. 원본 음악·영상·Miles Sound System 등은 각 권리자의 권리를 따릅니다.

개인 저장 파일, 편집기 백업, 게임 실행 로그, 메모리 덤프와 개발자의 개인 계정 정보는 배포 대상에서 제외했습니다.
