# v0.9.8 누적 변경 기록

## v0.9.8
아군 보스 5종을 적 진영인 좌상단을 향하는 새 시점 그림으로 교체합니다. 본체와 무기 54개를 분리하고 각 부품의 표시·발사·클릭 좌표를 연결했습니다. 원본 애니메이션의 길이와 프레임별 발사·효과 이벤트를 실행 중 복사하여 공격 빈도를 유지합니다. 새 아군 그림은 정지 스프라이트 기반이며 원본의 모든 프레임별 형태 변화를 새로 그리지는 않았습니다. 파괴된 무기의 표시와 개별 판정은 원래 전투 처리에 따라 제거됩니다. 적 보스 원본 자원은 유지하며, 전투 종료와 상태 갱신 때 소유한 그래픽 버퍼를 해제합니다.

## v0.9.7
배송 자동 이동에서 보병·항공 군단까지 전차 탑승 좌석 검사로 잘못 제외하던 문제를 수정했습니다. 한 군단만 주둔한 경우에도 출격 가능한 군단을 선택할 수 있습니다.

## v0.9.6
점령된 일반 도시 공격 시 해당 도시의 탈환 의뢰를 자동 수락합니다. 기존 의뢰는 같은 기록을 수락 상태로 바꾸고, 기록이 없으면 원래 의뢰 생성 함수로 생성합니다. 전투와 보상은 기존 처리로 이어집니다. 완료 후 보상 대기 중인 의뢰는 완료 상태를 보존하면서 재공격을 허용하며 보상을 중복 생성하지 않습니다. 적 용병단 본거지의 공격 자격과 이야기 전용 진입 조건은 유지합니다.

물품 배송 의뢰 수락 직후 자동 이동 여부를 선택할 수 있습니다. 자동 이동 선택 후 해당 도시의 출격 가능한 제1~9군단 중 하나를 고르면 월드맵으로 출격해 배송 목적지로 이동 명령을 내립니다. 군단이 많으면 목록을 넘겨 선택합니다. 출격 조건·이동 시간·경로·도중 전투·도착 후 인도 및 보상은 기존 규칙을 따릅니다. 취소하거나 출격할 군단이 없으면 의뢰만 수락합니다. 기존에 수락한 배송에는 선택창이 소급 표시되지 않습니다. 게임 저장과 개인 화면 설정은 변경하지 않습니다.

## v0.9.5
아군 보스형 장비 탑승자의 전투 경험치 누락을 수정했습니다. 일반 차량과 같은 원래 탑승자 경험치 및 레벨업 처리로 연결하고, 99레벨 탑승자 경험치 재분배와 개인 경험치 200 제한 제거도 적용합니다.

## v0.9.4
보관 중인 이벤트 보스형 장비를 포룸 F9에서 무료로 다시 배치할 수 있습니다. 호환하는 군단장 1명만 있는 군단이 필요하며 실제 보관 병기의 HP와 상태를 유지합니다. 아군 보스 본체·부품·선택 테두리를 좌우 반전하고 마우스 선택 판정도 맞췄습니다.

## v0.9.3
블랙크로우의 대기 중인 잔존 야전 부대가 최대 6일 간격으로 가까운 아군 점령 일반 도시를 재공격합니다. 아군이 철수한 빈 점거 본거지가 있으면 우선 재탈환합니다. 아군이 주둔 중인 본거지 안에서 적 병력을 생성하지 않습니다.

## v0.9.2
원본 보유자용 변경분 패치 배포로 전환했습니다. 원본 실행 파일·PAK·추출 게임 데이터·저장 파일을 공개 ZIP에 포함하지 않습니다. 설치 시 사용자의 검증된 원본으로 재구성하며 백업과 복원을 제공합니다.

## v0.9.1
아군 특수병기 5종이 적 진영 좌표에 그려져 적과 겹치던 문제를 수정했습니다. 원래 초기화·부품 갱신·클릭 판정 경로를 실행해 다섯 병기 양쪽 진영과 부품 108개의 위치를 검사했습니다. 기존 제작 병기와 저장 파일을 수정할 필요 없이 다음 전투부터 적용됩니다. 적 보스는 기존 위치를 유지합니다.

## v0.9.0
이벤트 성공 기록으로 특수병기 5종을 해금하고 포룸 F9에서 자원을 들여 제작·배치합니다. 빚 청산과 최종 승리 엔딩 뒤에도 월드맵에서 계속 진행합니다. 다른 일반 도시에 부대가 없는 적 용병단 6곳의 본거지를 공격·점거할 수 있습니다. 아군 주둔 본거지마다 월말 15만 겔더를 받으며 철수하면 적 충원·행동이 재개됩니다. 블랙드래곤은 파일럿·항공 군단, 나머지는 드라이버·장갑 군단에서 군단장 1명만 남겨 제작합니다. 상세 해금표·제작비·검증 범위는 확장캠페인-v090-사용법.txt를 참조하세요.

## v0.8.3
대화·선택창의 UTF-16 UI 리소스를 Windows 기본 코드페이지 대신 CP949로 변환합니다. UTF-8 옵션 또는 다른 비유니코드 언어 설정으로 인한 한글 표시 불일치를 수정합니다. 시스템 언어 설정과 저장 파일은 변경하지 않습니다. 실제 UI/경계값 문자열 102개를 949/1252/65001에서 검사하고 원본 불일치 192건을 재현하여 수정 후 출력 일치를 확인했습니다.

## v0.8.2
원본 의뢰 삭제 함수가 종류와 목적지가 같은 다른 의뢰를 지우는 문제를 수정했습니다. 보상을 지급한 의뢰 자체를 삭제합니다. 특정 개인 저장의 보석지팡이 복구는 일반 배포에서 실행하지 않습니다.

## v0.8.1
F8 사건 상세의 발동 조건과 강제 설정에서 조건 무시 예약을 켜고 끌 수 있습니다. 주요 사건 9개의 최초 발동 조건을 우회합니다. 미시작 값 0인 사건만 가능하며 시작·거절·완료 기록은 초기화하지 않습니다. 다른 사건 진행 중에는 대기하고, 발동하면 예약을 해제합니다. 후속 전투·퍼즐·전달은 직접 진행합니다.

## v0.8.0
