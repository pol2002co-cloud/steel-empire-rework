# 적 용병단 최대 편성 패치 v0.7.0

새로 자동 생성되는 6개 용병단의 병력을 기존 배치 규칙의 한도까지 증원합니다. 이미 저장된 부대와 고정 이벤트·보스 부대에는 적용되지 않습니다.

공통: 보병형 80명(군단장 포함), 기갑혼성형 전차 7대 + 보병 18명(승무원 포함 총 25명), 항공형 9기/조종사 9명. 블랙크로우의 원래 존재하지 않는 기갑 편성은 추가하지 않습니다.

| 용병단 | 보병형 병종 / 일반병 레벨 | 기갑형 전차 구성 | 항공형 구성 |
|---|---|---|---|
| 블랙크로우 | 동원병·경보병 / 초반 1–10, 이후 3–12 | 기존 미지원 유지 | 와이번 MK2 9기 |
| 화이트저스 | 동원병·경보병 / 5–15 | 고블린 MK2 7대 | 와이번 MK2 9기 |
| 아이언메이스 | 경보병·중보병 / 10–25 | 고블린 MK4 1대 + MK3 6대 | 와이번 MK4 9기 |
| 볼라이트닝 | 경보병·장갑척탄병 / 14–30 | 트롤 MK5 1대 + 고블린 MK3 5대 + MK8 1대 | 그리폰 MK5 1기 + 우드팩커 MK3 8기 |
| 레이크데빌 | 해병 / 23–40 | 키클롭스 1대 + 솔타리 MK2 6대 | A.S.6 1기 + 와이번 MK4 4기 + 나이트호크 4기 |
| 블랙파워 | 장갑척탄병·장갑보병 / 26–43 | 트롤 MK5 1대 + 고블린 MK4 4대 + 다우티 MK2 2대 | 와이번 MK4 6기 + 그리폰 MK5 3기 |

군단장 능력, 각 편성의 원래 레벨 범위, 무기 후보와 보병 병종 선택 확률은 유지합니다. 차량 증원은 원래 호위 차량 목록을 순환하여 채우며 군단장 전용 첫 차량은 증원 대상으로 복제하지 않습니다. 병력 수는 모두 최대이므로 약한 용병단도 이전보다 어려워집니다. 실전 난이도 조정은 아직 하지 않았습니다.

검증: 원본 생성 코드를 이용한 170회 에뮬레이션(객체 생성·장비 장착 함수는 대체), 126개 프로필 전후 비교, 이전 패치 바이트 보존 및 데이터 파일 동일성 확인. 실제 게임 내 전투 검증은 별도입니다.
