1. 실행 호환성 및 기본 런처
======================================================================

[현재 동작]
  - cnc-ddraw 7.1 기반의 DirectDraw 호환 계층을 적용했습니다.
  - 창 모드와 화면 확대를 지원하도록 실행 환경을 보완했습니다.
  - 초기 기본 설정은 1280×960, 원본 비율 유지, 렌더링 최대 60fps입니다.
  - 현재 화면 크기는 별도 와이드 런처의 선택과 사용자 설정에 따라
    달라집니다. 1280×960으로 항상 고정되는 것은 아닙니다.
  - 게임 진행 속도 자체를 임의로 빠르게 만드는 패치는 아닙니다.

[실행 파일]
  SteelRework.exe
    게임 폴더를 작업 경로로 지정해 SteelEmpire.exe를 실행합니다.
    실행 결과는 rework-launch.log에 기록합니다.

  SteelEmpire.exe
    실제 누적 패치가 적용된 게임 실행 파일입니다.

  _SteelEmpire.exe
    기존 배포본 실행기입니다. 리워크 실행에는 SteelRework 계열 런처를
    사용하면 실행 경로와 설정을 관리하기 편합니다.

[범위]
  Windows 11에서의 실행·표시 호환성을 보완한 것이며, 게임 엔진을
  새로 만들거나 모든 PC·그래픽 드라이버 조합을 검증한 것은 아닙니다.

2. 16:9 및 QHD 런처
======================================================================

SteelRework169.exe
  선택 해상도: 1280×720 / 1600×900 / 1920×1080

SteelReworkQHD.exe
  선택 해상도: 1280×720 / 1600×900 / 1920×1080 / 2560×1440
  기본 선택: 2560×1440

[사용 방법]
  1. 원하는 런처를 실행합니다.
  2. 해상도를 선택합니다.
  3. ‘16:9 창 모드로 실행’을 누릅니다.

[화면 표시 방식]
  - 원본 640×480 화면을 16:9로 가로 확대합니다.
  - 인물·글씨도 가로로 넓어집니다.
  - 지도나 전투에서 보이는 시야가 더 넓어지는 패치는 아닙니다.
  - 선택한 크기가 모니터의 작업 영역보다 크면, 16:9 비율을 유지하며
    실제 창 크기를 줄입니다. 따라서 QHD를 선택해도 표시되는 창이
    반드시 2560×1440 픽셀로 유지되는 것은 아닙니다.
  - 현재 설치된 SteelEmpire.exe를 실행하므로 최신 패치가 함께 적용됩니다.

[설정 보존]
  - 정상적인 게임 종료 후 기존 ddraw.ini를 복원합니다.
  - 실행 직전 설정은 WideLauncherBackups에도 보관합니다.
  - 런처 강제 종료나 컴퓨터 종료 때문에 복원이 누락되면, 게임을 종료한
    상태에서 실행 직전 ini 백업을 ddraw.ini로 복원할 수 있습니다.

4. 훈련대장 레벨 연동 신병 성장
======================================================================

훈련 완료 시점의 훈련대장 레벨을 기준으로 추가 레벨을 부여합니다.

  추가 보너스 = floor(max(0, 대장 레벨 - 1) / 3)
  최종 신병 레벨 = min(30, 기존 기본·병과·시설 보너스 + 추가 보너스)

구현에서는 계산에 사용하는 대장 레벨을 82까지 반영합니다.
그 이상은 이미 최종 신병 레벨 상한 30에 도달하므로 결과가 같습니다.

기존 기본 레벨:
  - 대장 없음: 1
  - 대장 있음: 3
  - 대장과 훈련 병과 일치: 6
  - 원래 시설 보너스가 있으면 추가 반영

시설 보너스가 없을 때의 예:
  대장 레벨       다른 병과 신병       같은 병과 신병
       1                3                    6
      10                6                    9
      30               12                   15
      60               22                   25
      90               30                   30

  - 대장이 없으면 대장 레벨 추가 보너스도 없습니다.
  - 완료 시점이 기준이므로 훈련 도중 대장을 바꾸면 결과가 달라집니다.
  - 게임의 원래 생성·레벨업 함수를 사용하므로 능력치도 성장합니다.
  - 기존 병사에게 일괄 적용하거나 재훈련 때 중복 적용하지 않습니다.

8. 포커 승리 고정과 술집 용병 즉시 고용
======================================================================

[포커]
  - 한 판의 최종 정산에서 플레이어를 승자로 지정합니다.
  - 약한 패 또는 기권한 판도 정산까지 진행하면 승리 판돈을 받습니다.
  - 카드 그림이나 실제 배분을 강한 패로 바꾸는 방식은 아닙니다.
  - 원래 판돈 차감·상금 지급 코드를 사용합니다.
  - 정산 전에 나가면 미정산 판돈을 강제로 지급하지 않습니다.

[술집 용병 — v0.7.4]
  - 술집의 고용 대상 용병은 포커 자금이 0인 상태로 들어옵니다.
  - 포커로 돈을 모두 잃게 만드는 과정을 거치지 않고 고용할 수 있습니다.
  - 고용 수락 판정은 호환도에 상관없이 원래의 무상 수락 경로를 사용합니다.
  - 플레이어가 직접 고용을 선택하고 확인하는 절차는 유지합니다.
  - 자동 영입 기능은 아닙니다.
  - 플레이어 자금이나 다른 술집 손님의 돈을 일괄 변경하지 않습니다.
  - 고용 대상이 아닌 이야기 속 등장인물을 모두 고용하는 기능은 아닙니다.

9. 전투 사망 동료의 다음 날 복귀
======================================================================

  - 플레이어가 영입한 이름 있는 동료를 전투 사망 후 명단에 보존합니다.
  - 게임 날짜가 바뀌는 다음 자정에 최대 HP로 회복합니다.

  - 월말 회복 처리 때문에 자정보다 일찍 돌아오지 않도록 보완했습니다.

적용 범위:
  영입 동료의 전투 사망 처리입니다. 일반 용병은 기존 사망 규칙을
  그대로 사용합니다. 이미 예전 저장에서 삭제된 동료를 재생성하거나
  모든 이벤트의 인물 퇴장·사망을 취소하는 기능은 아닙니다.

10. 항공 부대의 도시 진입과 출격
======================================================================

[착륙]
  항공 부대가 도시 진입 가능 여부를 검사할 때 공항 보유 조건을 해제했습니다.
  공항이 없는 도시도 착륙 대상으로 판정합니다.

[공항 없는 도시에서 다시 나가는 방법]
  1. 항공 부대가 주둔한 도시의 기본 화면으로 들어갑니다.
  2. A키를 누릅니다.
  3. 열린 공항 화면에서 부대를 선택해 기존 출격 절차를 진행합니다.

  - 공항 건물을 실제로 건설하는 방식은 아닙니다.
  - 조종사·탑승 조건과 기존 부대 조작 절차를 유지합니다.
  - 적대 관계와 주둔 부대 수 등의 다른 진입 제한은 유지합니다.

11. 군단장 사망 후 전투 처리
======================================================================

적 군단장이 죽었다는 이유만으로 잔여 적을 남겨 두고 즉시 승리하던
처리를 변경했습니다.

  - 적 군단장이 죽고 적이 남아 있으면 전투를 계속합니다.
  - 군단장이 죽은 턴을 기준으로 3턴 뒤를 전멸 시점으로 설정합니다.
  - 그 시점까지 살아 있는 적을 자동 사망 처리하고 원래 전투 정산으로 갑니다.
  - 그 전에 직접 적을 모두 없애면 먼저 승리합니다.
  - 원래 전투 제한이 더 짧으면 해당 처리까지 진행할 수 있게 연장합니다.

예: 1턴에 적 군단장이 죽으면 4턴 시작 시 잔여 적이 자동 전멸합니다.

아군 군단장 사망에 의한 패배와 수동 퇴각 규칙은 그대로입니다.

12. 브라보니케 치트의 즉시 승리
======================================================================

기존 ‘브라보니케’ 인식 경로를 유지하면서 효과를 강화했습니다.

  - 기존 치트 입력이 인식되면 현재 전투의 적을 모두 사망 처리합니다.
  - 군단장 사망 후의 3턴 대기를 건너뛰고 즉시 정상 승리 정산으로 넘어갑니다.
  - 적 군단장만 죽이는 효과에서 전투 전체 종료 효과로 변경했습니다.
  - 기존 전투 정산 절차를 이용하므로 보상 값을 별도로 임의 생성하지 않습니다.

입력 참고:
  기존 키보드 입력 순서인 qmfkqhslzp가 ‘브라보니케’에 해당합니다.
  원래 게임이 치트 입력을 받는 전투 대기 상태에서 입력해야 합니다.
  대화·연출 등 어떤 상태에서든 입력을 강제로 받도록 바꾼 것은 아닙니다.

14. 99레벨 인물의 경험치 균등 재분배
======================================================================

  - 전투 정산 시 이미 99레벨인 생존 인물이 받을 경험치를 모읍니다.
  - 기본 전투 경험치와 해당 인물의 처치 보너스를 포함합니다.
  - 같은 전투의 생존한 99레벨 미만 대상자에게 균등하게 나눕니다.
  - 보병뿐 아니라 차량·항공기 내부의 개별 승무원도 대상입니다.
  - 분배는 부대 하나당이 아니라 경험치를 받는 인물 단위입니다.
  - 각 대상자는 자신의 원래 경험치에 재분배 몫을 추가로 받습니다.

정수 분배:
  모인 경험치를 대상자 수로 나눈 몫을 모두에게 지급합니다.
  나머지는 일부 대상에게 1씩 더해 총량을 보존합니다.

예: 99레벨 인물의 경험치 101이 모이고 대상자가 4명이면,
    26 / 25 / 25 / 25로 분배합니다.

제한:
  - 사망한 전투 인물은 재분배 대상에서 제외합니다.
  - 모두 99레벨이면 나눠 받을 사람이 없으므로 재분배하지 않습니다.
  - 이번 보상으로 98에서 99가 되는 인물의 초과 경험치를 다시 회수해
    두 번째로 나누는 기능은 아닙니다.
  - 전투에 참가하지 않은 다른 군단 전체에 경험치를 보내지 않습니다.

오른쪽 편집 영역을 아래로 스크롤하면 능력과 상태 항목이 보입니다.

[편집 가능한 수치와 입력 범위]
  레벨                      1~99
  현재 HP                   0~99,999
  최대 HP                   1~99,999
  현재 경험치               0~9,999,999
  다음 레벨 필요 경험치     1~9,999,999

  군단 방어 보정            -100~100

위 범위는 에디터의 일반 입력 범위이며, 게임에서 자연 성장하는 정상
능력치 범위를 뜻하지 않습니다. 기존 저장의 범위 밖 값은 표시를 위해
입력 범위가 확장될 수 있습니다.

[포룸 밖 인물]
