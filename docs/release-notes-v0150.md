# 강철제국 리워크 v0.15.0 누적 업데이트 안내

안녕하세요. 강철제국 리워크 v0.15.0을 배포합니다.
마지막 공개 버전인 v0.10.0 이후 로컬에서만 적용했던 수정과 신규 콘텐츠를 이번 누적 패치에 모두 담았습니다. 이전 버전을 하나씩 설치할 필요 없이 최신 PatchOnly ZIP 하나를 적용하시면 됩니다.

## 1. 남는 인원을 활용하는 해외 파견
- 기존 9개 군단과 별도로 파견대 4개를 운영합니다. 파견대마다 대장 포함 영웅 최대 3명, 일반 병사 최대 20명이 참여합니다.
- 엑제로스 공국 군사 교류·기술 협력, 동방대륙 무역 호위·현지 조사와 유적 탐험으로 경험치·지급금·설계도를 얻습니다.
- 임무만 고르면 대장과 대원을 자동 추천합니다. 실제 성공률 → 추가 지급률 → 참가 인원수 → 평균 레벨 순으로 비교합니다.
- 출발 전 명단·기간·준비금·예상 순수익을 확인합니다. 배치·보직·훈련·다른 파견 중인 인원은 제외하며, 진행 중인 같은 임무에 새 인원을 추가 파견할 수도 있습니다.

## 2. 전역 이벤트 38종과 퀘스트 편의성
- 추가 사건을 방문·점령·물자·물품·장비 준비·건물 완공처럼 한 가지 목표로 정리했습니다. 조건이 맞는 사건은 본편 진행 중에도 발생합니다.
- 특정 담당 군단·필수 인물·복잡한 경유지를 요구하지 않습니다. 어느 아군이든 해당 목표를 달성하면 자동 정산합니다. 점령은 실제 전투·주둔 결과를 확인합니다.
- 새 소식과 진행 결과를 원본 대화창으로 안내하며, F8에서 목표·현재 진행·부족한 수량·남은 보상을 확인할 수 있습니다.
- 목표 도시로 이동 명령을 내릴 수 있습니다. 고블린MK2 등 장비 납품은 포룸 정비창의 완전히 수리된 미배치·미탑승 재고를 사용하며, 별도 배송 군단은 필요하지 않습니다.

## 3. 민간군단 자동 순회 공연
- F8에서 설정한 민간군단이 안전한 비적대 일반 도시를 순회하며 댄서의 공연 수입과 경험치를 얻습니다.
- 시청·정부청사 건설을 요구하던 잘못된 조건을 제거했습니다. 공연 후에는 휴식 시간을 두고 다음 도시로 이동합니다.

## 4. 유적 탐험·설계도·희귀 보물
- 실제 방문한 유적에는 별도 탐험대를 보낼 수 있으며, 고블린MK2·드래곤MK2·A.S.6 제작 설계도를 발견할 수 있습니다.
- 연간 유적 보상에는 저장고·보물·별빛 제단·아주 드문 왕실 보물고가 추가됩니다. 파견 성공률·소요 기간·경험치 등에 자동 적용되는 영구 유물도 있습니다.
- 같은 유적·같은 연도의 추가 발견 결과를 저장해, 메뉴를 다시 열거나 불러오는 것만으로 재추첨되지 않도록 했습니다.

## 5. 이번 최신 기능: 유적 수호대 실제 전투
유적마다 게임 연도에 한 번, 다음 3단계 전투에 도전합니다.

| 단계 | 적 편성 | 레벨 |
|---|---|---:|
| 1단계 | 보병 80명 | 30 |
| 2단계 | 항공기 9기와 조종사 | 40 |
| 3단계 | 전차 7대·승무원 7명 + 보병 18명 | 50 |

- 카푸아·펠라·케브·고대유적마다 병종과 장비 비중이 다릅니다. 보스형을 제외하고 레드울프·드레드노트 등 상위 일반 장비와 보병 무장을 조합했습니다.
- 원본 전투 화면에서 직접 싸웁니다. 단계 승리 후 정비하거나 군단을 교체하고 이어갈 수 있습니다.
- 패배·퇴각하면 해당 유적의 올해 도전은 종료됩니다. 다음 게임 연도에 실제로 재방문하면 1단계부터 다시 도전합니다.
- 3단계를 모두 승리하면 기존 연간 혜택과 보물을 받습니다. 올해 이미 연간 보상을 받은 기존 저장은 다음 해부터 수호대가 적용됩니다.

## 6. 함께 반영한 주요 버그 수정
- 이벤트 후 블랙파워가 복귀하지 않던 문제와 지휘자 기록 누락 복구
- 엑제로스 본편 최종 승리 후 해당 지역을 배송 목적지로 개방하고 이동·수송 처리 보완
- 저장 불러오기 중 자동 대화 때문에 검은 화면에서 멈추던 문제
- 인물 에디터 병과 변경 후 운전병의 차량 탑승·중장갑보병의 캐틀링 장비 자격이 반영되지 않던 문제
- 해병교육소 선행 조건을 중화기사격장 완공으로 수정
- 장갑보병 → 중장갑보병 재훈련 방어 증가를 +15로 조정(45 → 60), 재훈련 완료 알림 추가
- 납품 장비 분류 오류와 미지정 민간군단의 0번 표시 수정
- 퀘스트·파견·유적의 저장 복원, 지급 대기 및 보상 중복 방지 보완
