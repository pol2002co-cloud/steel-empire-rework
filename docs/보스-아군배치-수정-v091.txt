강철제국 리워크 v0.9.1 — 아군 보스 배치 수정

원인
원본의 대형 보스 초기화 함수는 소속과 관계없이 적 진영의 표시 좌표를 사용했습니다.
F9로 만든 아군도 적 쪽에 그려져 적 보병과 겹쳐 보였습니다.
전투 배치 개체가 생성되는지만 확인한 v0.9.0의 검사로는 이 표시 좌표 문제를 잡지 못했습니다.

수정
아군 INF MK1·MK2, 블랙드래곤, 랜드배틀쉽, 포트레스의 본체 표시 원점을 아군 진영으로
이동합니다. 원래 포탑과 부품 위치 갱신 함수를 사용하므로 부품·선택 판정이 함께 이동합니다.
능력치 갱신 뒤에도 적 진영으로 되돌아가지 않습니다. 블랙드래곤의 공중 부유 높이도 유지합니다.
적 보스는 기존 좌표를 그대로 사용합니다.

사용 방법
게임과 런처를 종료하고 업데이트를 설치한 뒤 다시 실행하세요.
이미 제작한 병기는 다시 만들 필요 없이 다음 전투부터 수정됩니다.
병기·인물·이벤트·군단 편성과 저장 파일은 수정하지 않습니다.
v0.9.0의 이벤트 해금·제작·엔딩 이후 진행·본거지 점거 기능을 포함합니다.

검증
원본 대형 병기 생성자와 초기화·부품 위치 갱신·클릭 판정 코드를 실제로 실행하여
다섯 병기 × 아군/적군의 좌표를 검사했습니다. 수정 전 아군 다섯 종류의 오배치를 재현했고,
수정 후 부품 108개의 좌표와 클릭 위치, 능력치 재갱신, 공중 부유를 검사했습니다.
기존 캠페인·저장 복원·전투 정산·한글 변환 검사도 통과했습니다.
그림 리소스 로딩은 검사 환경에서 대체했으며, 사용자 PC의 실제 플레이 화면 재확인은 별도입니다.
