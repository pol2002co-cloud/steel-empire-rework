# 강철제국 리워크 v0.8.0: 이벤트 진행창

월드맵 또는 도시의 기본 화면에서 **F8**을 누릅니다. 별도 프로그램을 실행하지 않고 게임의 선택창과 대화창으로 표시합니다. 전투나 다른 대화창 안에서는 열지 않습니다.

- 사건은 한 페이지에 3개씩 표시됩니다. **다음 페이지**로 넘기며, 마지막 페이지 다음에는 처음으로 돌아옵니다.
- 사건 선택 후 **현재 단계와 다음 진행**, **발동 조건 모두 보기**, **전체 진행 순서와 선택 분기**, **관련 진행 기록**을 조회합니다.
- 마지막 목록 페이지에는 **전체 세부 진행 기록**, **시작 조건의 현재 값**, **안내**가 있습니다.
- 설명은 일반 게임 대사처럼 클릭하여 넘깁니다. **사건 목록으로**, **닫기 - 게임으로**로 돌아갑니다.

시작과 상속, 주디스, 라이벌, 인도하는자, 밀로셰비치대령, 그락쿠스형제, 고대인의유적, 깽디쉬박사, 최후의결전의 9개 주요 사건을 모두 공개합니다. 아직 만나지 않은 사건의 조건과 선택 결과도 볼 수 있습니다.

관련 기록 16개에는 잽·스톤해머 격파, 밀로셰비치 살해 선택, 신의 눈 세 지역 진행, 샤르데나 수도 진입, 세 도시 해방, 파멸의 달 누적, 유적 완료 연월, 다음 파멸의 달 연월일이 포함됩니다. 조건 현재 값에서는 비트만 레벨, 동료 명단 인원, 편성 군단 수, 부채, 다른 사건 진행 여부, 현재 날짜를 조회합니다.

## 표시를 읽는 방법

**미시작은 저장 값 0**입니다. 이미 종료한 사건을 미시작으로 취급하지 않습니다. 예를 들어 라이벌을 종료하면 고대인의유적 시작 조건의 ‘라이벌 미시작’을 만족하지 못합니다.

**종료는 무조건 성공을 뜻하지 않습니다.** 원본은 라이벌의 최초 거절, 인도하는자의 거절·퍼즐 실패·전달 완료 등을 같은 값 10으로 저장합니다. 기존 저장 파일에서 구별할 근거가 없을 때는 가능한 분기를 함께 표시합니다. 강제 편집으로 생긴 알 수 없는 값은 숫자와 함께 미확인 단계로 표시합니다.

조건을 충족했더라도 해당 건물을 방문하거나 월드맵의 이벤트 처리 시점이 와야 사건이 발생합니다. 설명의 시작 조건은 모두 함께 충족해야 합니다. 도시 의뢰의 수락/보고 대기 상태는 해당 도시 관청에서도 확인하세요.

진행창은 진행 상태를 읽기만 합니다. 사건을 강제로 시작하거나 완료하지 않으며, 저장 형식도 바꾸지 않습니다. 창을 보고 있는 동안에는 월드맵 시간이 진행되지 않습니다. 일반 도시 의뢰는 주요 이야기 사건 9개와 별개의 기존 의뢰 시스템입니다.

## 검증과 설치

조건의 근거는 설치된 게임의 patch102.pak에 있는 78개 컴파일된 스크립트와 실행 파일의 상태 조회 코드입니다. 외부 공략을 추정하여 입력한 조건이 아닙니다.

기계어 에뮬레이션으로 97개 상태·조건·진행 표시 사례, 메뉴 순환, 관련 값 16개, F8 화면 제한, UI 함수 인자·해제, 이벤트 값 미변경을 검증했습니다. 이전 v0.7.4 코드의 변경 범위도 F8 연결과 새 기능 영역으로 제한했음을 확인했습니다. 실제 게임 화면에서의 표시와 조작은 별도 확인이 필요합니다.

기존 전투·재훈련·경험치 분배 검증도 통과했습니다. 설치는 `Install-v080.ps1`이 게임과 런처가 종료된 것을 확인한 후 기존 실행 파일을 백업하고 `SteelEmpire.exe`만 교체합니다. 이전 패치, 저장 파일과 런처 설정은 유지합니다.
