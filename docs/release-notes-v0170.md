# 강철제국 리워크 v0.17.0

강철제국 리워크 v0.17.0 누적 패치입니다. 기존 저장에서 이어서 플레이할 수 있습니다.

- **연간 행사** · 1·7월에는 도시 탈환·점령 의뢰금과 주둔 본거지 상납금, 3·9월에는 아군 전투 경험치, 5·11월에는 배송·납품 의뢰금이 두 배입니다. 보수는 정산하는 달을 기준으로 계산합니다.
- **전설 장비 4종** · 유적 2곳을 방문하면 철왕, 유적 연간 혜택을 1회 받으면 뇌격전차, 파견 귀환을 3회 정산하면 천둥매, 서로 다른 유적 2곳의 심층 봉인실에서 보존 또는 회수를 선택하면 밤까마귀 설계도가 열립니다. 기존 달성 기록도 인정합니다.
- **제작** · 포룸에 연구소와 해당 3단계 공장을 완공한 뒤 F8 → 해외 파견·유적 → 유적·설계도·유물 장부 → 설계도 제작에서 주문하세요. 완성까지 18~24일이 걸립니다.
- **v0.15.0 이후 누적 변경** · 기존 전역 의뢰 38종의 의뢰문과 결과문을 다듬고, 무전 구조·인양·앙코르 공연 3종을 추가했습니다. 퀘스트와 파견의 주요 소식에는 본편 이벤트 액자에 맞춘 삽화가 나옵니다.

원본 게임 보유자용입니다. 기존 사용자는 리워크 런처에서 업데이트하거나, 아래 **SteelEmpire-Rework-v0.17.0-PatchOnly.zip**을 내려받아 압축을 풀고 **Install-Patch.cmd**를 실행하세요. 설치 전에 게임·런처·에디터를 종료하세요. **PatchSource.zip**은 패치 소스입니다.
