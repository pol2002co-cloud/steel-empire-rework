강철제국 리워크 v0.15.0 — 유적 수호대

시작 방법
카푸아·펠라·케브 유적 또는 월드맵 고대유적을 전투 군단으로 실제 방문하면
수호대 안내가 자동으로 표시됩니다. 전투 시작은 명단 확인 후 직접 선택합니다.
원본 유적의 접근 조건·스토리·숨겨지는 시점은 그대로 적용됩니다.

연간 1회 도전
각 유적마다 게임 연도에 한 번, 최대 3단계에 도전합니다.
1단계: Lv30 보병 80명
2단계: Lv40 항공기 9대와 조종사 9명
3단계: Lv50 전차 7대와 승무원 7명 + 보병 18명 (총25명)
보스형 장비는 사용하지 않습니다. 일반 병과·무기·탱크·항공기만 사용합니다.
실제 원본 전투 화면에서 싸우며 부상·사망·퇴각·경험치는 기존 전투 규칙입니다.

유적별 특징
- 카푸아: 장갑보병 중심 → 와이번MK4 중심 항공 → 레드울프4/드레드노트2/
  키클롭스1 + 중장갑보병12/장갑척탄병6
- 펠라: 해병 중심 → 나이트호크 중심 항공 → 레드울프3/유니콘2/
  드레드노트1/키클롭스1 + 해병8/중장갑보병6/장갑척탄병4
- 케브: 장갑척탄병 중심 → 그리폰MK5 비중이 높은 항공 → 레드울프3/
  키클롭스2/드레드노트2 + 장갑척탄병10/중장갑보병8
- 고대유적: 보병 균형형 → A.S.6·나이트호크 혼성 항공 → 레드울프3/
  유니콘1/드레드노트2/키클롭스1 + 해병6/중장갑보병6/장갑보병6
최종 편성은 블랙파워의 기본 차량보다 전체 내구도·방어 및 대공 성능이 높은
일반 장비와 상위 보병 무장을 조합합니다. 적 레벨은 아군 레벨에 따라 늘지 않습니다.

전투 진행과 정비
1단계 승리 후 2단계, 2단계 승리 후 3단계 안내가 자동으로 표시됩니다.
바로 진행하지 않아도 같은 해의 승리 단계는 저장됩니다. 정비·부대 교체 후
F8 → 해외 파견·유적 → 유적·설계도·유물 장부 → 유적 방문·연간 혜택에서
해당 유적을 골라 이어갈 수 있습니다. 다른 유적의 진행은 각각 독립적입니다.
도시 유적은 해당 도시에 주둔한 전투 군단 중에서 고릅니다.
월드맵 고대유적은 실제 접촉한 군단이 방문 위치에 있어야 합니다.
이동·저장 불러오기 후에는 월드맵 유적에 다시 접촉해야 전투를 시작할 수 있습니다.
민간군단은 전투에 참여하지 않습니다. 항공 수호대에는 대공 무장이나 항공군단을 권장합니다.

패배 또는 퇴각하면 해당 유적의 올해 도전은 종료됩니다. 다음 게임 연도에
실제 재방문하면 1단계부터 새로 도전할 수 있습니다. 게임의 1년은360일입니다.
전투 준비·메모리 할당 실패나 시작 전 취소는 도전 기회를 사용하지 않습니다.
이미 시작한 전투를 자동 승리 처리하거나 다른 전투 결과를 가져오지 않습니다.

승리 보상
3단계를 모두 승리한 뒤 기존 연간 물자·성장·회복 혜택 중 하나를 선택하고,
저장된 연간 추가 발견 결과(보물·유물 등)를 함께 받습니다. 보상은 연간1회입니다.
기존 보존 유적의 기본 물자·경험치50% 증가는 유지합니다.
추가 발견 확률: 일반70%, 저장고20%, 보물8.5%, 별빛제단1.4%, 왕실보물고0.1%.
별빛제단 영구유물과 중복 대체금, 원본 스토리 유적 조건도 유지합니다.
올해 이미 연간 혜택을 받은 기존 저장에는 추가 전투·보상을 중복 생성하지 않습니다.
다음 게임 연도에 다시 방문하면 수호대가 적용됩니다.

저장·호환성
기존340바이트 확장 저장 형식을 유지합니다. 유적별 단계·승패는 저장·불러오기에
유지됩니다. 원본 전체 게임 데이터와 개인 세이브를 배포 파일에 포함하지 않습니다.

파견 자동 추천(v0.14.1 유지)
F8 → 해외 파견·유적 → 파견 보내기에서 임무만 고르면 대장·동료·일반 병사를
자동 추천합니다. 실제 성공률 → 추가 지급률 → 참가 인원수 → 평균 레벨 순입니다.
출발 전 명단·비용·보상을 확인하며 기존 군단·보직·훈련 중 인원을 빼오지 않습니다.
취소하면 준비금과 인원은 변경하지 않습니다. 기존9군단과 별도4파견대를 사용합니다.
